# Event Management System (EMS)

## Course Details
* **Course Code:** BCA124-2OL
* **Institution:** Christ University

## Project Description
The Event Management System (EMS) is a web application designed to streamline event discovery, ticket purchasing, and organizer management into a single platform.

## Proposed Modules
1. **Home:** Overview of featured, upcoming, and trending events.
2. **Login:** Authentication portal for users, event organizers, and administrators.
3. **User Registration:** Signup interface for new users to set preferences and create accounts.
4. **Event Search & Filter:** Dynamic search bar with filters for event categories, dates, and locations.
5. **Event Booking & Ticketing:** Interface to select ticket quantities, seat tiers, and complete bookings.
6. **Payment Gateway Integration:** Mock/Live payment checkout generating instant digital receipts.
7. **Organizer Dashboard:** Administrative portal to create, edit, and track event listings and attendee numbers.
8. **User Profile & Booking History:** Dashboard displaying upcoming registered events, downloadable tickets, and QR codes.

## Tech Stack (Planned)
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** Node.js / PHP / Python
* **Database:** MySQL / MongoDB
